# Homepage Feature Branch

This branch contains the implementation of the main homepage for our website.

## Files

- `index.html` - Main HTML structure for the homepage
- `styles.css` - CSS styling for the homepage
- `script.js` - JavaScript for interactive elements

## Features

- Responsive navigation with active state
- Hero section with call-to-action
- Services/features section with hover effects
- Call to action section
- Fully styled footer
- Simple animations and interactions with JavaScript

## Implementation Details

The homepage is designed with a clean, modern look and includes all essential elements for a business website's landing page. JavaScript is used to enhance the user experience with smooth animations and interactive elements.
