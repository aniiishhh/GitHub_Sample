# Responsive Design Branch

This branch focuses on implementing responsive design features for our website.

## Files

- `index.html` - Basic HTML structure for the website
- `styles.css` - CSS styles with responsive design using media queries

## Responsive Features

- Mobile-friendly navigation menu
- Flexible layout for different screen sizes
- Responsive text sizing
- Card layout that adjusts to screen width

## Testing

View the page on different device sizes to see the responsive behavior:

- Desktop (> 768px)
- Tablet (768px)
- Mobile (480px)
